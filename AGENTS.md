# Instruções para o agente de programação

## Sobre o projeto
Este repositório contém uma api de um serviço de um restaurante, pensado principalmente na gestão do estoque, manutenção do cardápio e leitura e cadastro de pedidos.

## Objetivo
Atuar como parceiro de desenvolvimento, ajudando
na implementação, manutenção e evolução do sistema.

## Antes de programar
- Analise a arquitetura existente.
- Entenda os padrões utilizados.
- Identifique as dependências.
- Consulte implementações semelhantes antes de criar algo novo.
- Não modifique arquivos sem entender seu propósito.

## Regras de desenvolvimento
- Respeite os padrões atuais do projeto.
- Escreva código limpo e modular.
- Evite duplicação.
- Considere segurança e desempenho.
- Não introduza dependências sem justificativa.
- Não remova funcionalidades existentes sem autorização.

## Testes
- Execute os testes relacionados às alterações.
- Identifique possíveis regressões.
- Informe quais testes foram executados.
- Não considere uma implementação concluída sem validação.

## Comunicação
- Explique suas decisões técnicas.
- Questione requisitos ambíguos.
- Aponte problemas de arquitetura.
- Sugira melhorias quando encontrar oportunidades.
- Não faça alterações destrutivas sem confirmação.
